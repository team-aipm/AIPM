# 메티 핵심 학습 메커니즘

> **Version:** 1.0  
> **Updated:** 2026-09-28  
> **Status:** 확정

한 줄 정의: 학생이 자신의 생각을 설명하거나 AI의 오류를 찾아 고치면서, 자신이
무엇을 알고 모르는지 발견하는 메타인지 학습.

## 1. AI가 미션을 내는 경우

- AI가 학년, 난이도와 Student Memory를 반영해 미션 1개를 낸다.
- 학생이 답과 풀이 이유를 설명한다.
- AI는 정답 여부만 알리지 않고 판단, 근거, 규칙, 전이와 성찰 중 부족한 부분을
  질문한다.
- 학생이 스스로 수정하도록 돕고 관찰 가능한 항목만 평가한다.

## 2. 학생이 미션을 내는 경우

- 학생이 사진 또는 텍스트로 미션을 가져온다.
- 서비스가 미션 내용과 정답을 검증한다.
- 별도의 답 인지 확인 화면 없이 AI가 교육 목적의 의도적 오답 풀이를 보여준다.
- 학생은 틀린 부분을 찾고 왜 틀렸는지 AI에게 설명한다.
- 학생이 `잘 모르겠어`를 선택하면 AI와 함께 풀기·힌트 흐름으로 전환한다.

학생에게 `내가 풀어볼래 / AI한테 내볼래`와 같은 모드 선택을 제공하지 않는다.
학생이 가져온 미션이라는 행위 자체가 AI를 가르치는 흐름으로 연결되며, 대화 중
도움이 필요하다고 표현할 때 함께 풀기로 전환한다.

## 3. 의도적 오답

- 학생이 가져오고 정답 검증이 완료된 미션에서 사용한다.
- 하루 10개 중 특정 횟수를 강제로 채우지 않는다.
- Answer Lock과 다른 결과 또는 잘못된 추론을 의도적으로 만든다.
- 실제 모델 오류와 별도 상태로 기록한다.
- 학생이 발견할 수 있는 수준에서 시작하고 필요하면 단서를 제공한다.
- 조롱, 함정과 실패 유도가 아니라 오류 탐지와 설명 학습이 목적이다.

## 4. 사진

- 사진은 입력 수단이지 학습기록이 아니다.
- OCR 결과를 학생이 확인한 뒤 확정 텍스트와 구조화 데이터만 저장한다.
- 원본과 임시 파일은 즉시 삭제한다.
- 도형·그래프를 완전하게 구조화하지 못하면 학습하지 않고 재촬영 또는 텍스트
  입력을 안내한다.

## 5. Adaptive Drill-down

- 미션당 최대 5회 질문한다.
- 5단계를 모두 기계적으로 거치지 않는다.
- 이미 확인된 사고는 건너뛰고 부족한 부분에 집중한다.
- 이해가 확인되면 조기에 완료한다.
- 미션을 오래 붙잡아 정답을 강요하지 않는다.

관찰 영역:

- 최초 판단
- 이유 설명
- 규칙 이해
- 스스로 수정
- 다른 상황으로 전이
- 성찰
- 실제 도움 수준

각 영역은 관찰했을 때만 0~3으로 평가하며 관찰하지 못한 경우
`not_observed`로 저장한다.

## 6. 일일 리듬

- 월~금 오늘의 미션 10개를 제공한다.
- 한 미션씩 생성해 직전 결과를 다음 미션에 반영한다.
- 학생이 가져온 검증 완료 미션도 당일 기본 10개에 포함할 수 있다.
- 날짜가 바뀌면 새 10개를 시작한다.
- 남은 미션은 7일 동안 지난 미션 목록에서 자율적으로 진행한다.
- 주말에는 새 일일 미션 없이 지난 미션 또는 가져온 미션만 자유롭게 학습한다.

## 7. 동기부여

- 평일 일일 기본 미션 10개를 모두 완료하면 하루 도장 1개를 받는다.
- 일일 기본 미션이 `completed/needs_review`로 끝나면 미션당 10코인, 하루 최대
  100코인을 받는다.
- 중간에 이탈해도 완료한 미션의 코인은 유지하며, 10개 미완료 시 도장은 받지 않는다.
- 보호자와 협의한 보상 목표는 도장으로 채운다.
- 메티·헤티는 기본 제공하고 큐리 500, 포키 800, 토리 1,200, 모노 2,000코인을
  사용해 영구 해금한다.
- 연속기록은 보조 정보이며 실패·처벌처럼 표현하지 않는다.
- 캐릭터는 말투와 긍정적 피드백을 돕지만 학습 내용보다 강조하지 않는다.
