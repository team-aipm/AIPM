# Figma 전체 페이지 섹션 배치 검수

> 검수일: 2026-09-29  
> 대상: `메티_화면 작업 중~` 전체 10개 페이지

## 결론

- 활성 플로우 섹션 간 겹침 없음
- 섹션 밖으로 이탈한 화면 없음
- 화면 간 비의도적 겹침 없음
- 학생·보호자·상태·탐색·Archive 페이지의 섹션 순서와 번호 정리 완료
- 주석 위젯과 디자인 시스템의 원본 컴포넌트는 의도적으로 섹션 밖에 유지

## 수정한 배치

### 학생 흐름

- 활성 페이지에 섞여 있던 이전 미션 대화안을 Archive로 이동
- 오늘 미션 완료 후 지난 미션을 자동 권유하던 화면을 Archive로 이동하고 학습 시작
  섹션의 빈 공간을 제거
- 보류 중 온보딩 시안을 Exploration으로 이동
- 활성 섹션을 `01 진입`부터 `09 친구 열기`까지 연속 번호로 정리

### 보호자 흐름

- 섹션 밖에 빠져 있던 `비밀번호 재설정 / 02-a 학생 계정 안내`를
  비밀번호 재설정 섹션으로 복구
- `자녀 계정 목록 / 최대 2명`을 Archive로 옮긴 뒤 남아 있던 빈 한 칸을 제거하고
  계정 상세부터 삭제 확인까지 모든 화면을 왼쪽으로 연속 배치
- 활성 목록 상태를 `기본 2/3 → 최대 3명 3/3 → Empty 0/3` 순서로 배치
- 기본 흐름을 `01 → 02 → 02-a → 03 → 휴대폰 본인확인 → 새 비밀번호 → 완료`
  순서로 첫 행에 배치
- 입력 오류·발송 실패·링크 만료·본인확인 실패·비밀번호 오류 상태는 아래 행으로 분리

### 상태와 예외 상황

- 제거된 프로필 선택 섹션 때문에 남아 있던 상단 2,876px 빈 공간 제거
- 섹션 번호를 현재 구성에 맞춰 `01`부터 `14`까지 다시 부여

### Exploration

- 온보딩 보류 시안을 `04 · Onboarding Options` 섹션으로 이동
- 기존 탐색 섹션과 100px 간격으로 연속 배치

### Archive

- 기존 보관 섹션 번호와 순서를 재정리
- 섹션 없이 흩어져 있던 화면을 다음 그룹으로 정리
  - 이전 학생 전환 화면
  - 이전 IA 항목
  - 이전 자녀 계정 정책
  - 이전 미션 대화 흐름
- 10px 간격으로 겹쳐 있던 자녀 정보 수정 화면을 3열 2행으로 재배치

## 의도적으로 유지한 항목

- 학생·보호자 페이지 왼쪽의 Annotation Sticky Notes는 검토 메모이므로 섹션 밖 유지
- Components 페이지의 메인 프레임, 원본 컴포넌트 세트와 에셋 섹션은
  디자인 시스템 편집 구조이므로 화면 플로우처럼 강제 재배치하지 않음
- 이전 미션 대화 흐름의 화살표 교차는 플로우 연결 표현이므로 화면 겹침 오류에서 제외
